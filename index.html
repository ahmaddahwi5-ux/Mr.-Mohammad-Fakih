خطوات الرفع على السيرفر (Production Ready Stack):

1. تحويل Backend إلى Express.js + PostgreSQL / Firebase:

// Example Backend Route to prevent Double Booking
app.post('/api/bookings', async (req, res) => {
  const { courtId, date, timeSlot } = req.body;
  const existing = await db.query(
    'SELECT * FROM bookings WHERE court_id = $1 AND date = $2 AND time_slot = $3 AND status = $4',
    [courtId, date, timeSlot, 'CONFIRMED']
  );
  if (existing.rows.length > 0) {
    return res.status(400).json({ error: 'عذراً، التوقيت محجوز مسبقاً!' });
  }
  // Insert Booking...
});

2. استضافة المنصة مجانًا على Vercel أو Netlify:

  • قم برفع هذا الملف (`index.html`) إلى مستودع GitHub.
  • قم بربط المستودع بموقع Vercel.com أو Netlify.com.
  • سيكون الموقع جاهزاً ويعمل بنطاق مجاني أو نطاق خاص مثل (`www.kora-padel-lb.com`).
